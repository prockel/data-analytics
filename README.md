League of Legends — First Blood & Win Rate

Status: In Progress

An exploratory data analysis using the Riot Games API to investigate whether the role securing first blood is associated with a team's probability of winning.

Research questions:

Does the role that secures first blood affect the team's win rate?
Does this relationship change across ranked skill levels?
Is the relationship different between lower-, mid-, and high-elo games?

Tools: Python · SQL · Pandas · Matplotlib · Riot Games API
